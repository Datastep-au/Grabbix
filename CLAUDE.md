This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- **Dev server:** `npm run dev` (runs frontend + backend with HMR)
- **Build:** `npm run build` (Vite frontend → `dist/public`, ESBuild backend → `dist/index.js`)
- **Start production:** `npm run start`
- **Type check:** `npm run check`
- **DB migrations:** `npm run db:push`

No test runner is configured.

## Architecture

Full-stack TypeScript monorepo: React frontend + Express backend, sharing types via `shared/`.

### Directory Layout

- `client/src/` — React app (Vite, Wouter routing)
  - `pages/` — Route pages (home, contact, locations, location/:slug, use-cases/:slug, etc.)
  - `components/sections/` — Page section components (hero, nav, footer)
  - `components/ui/` — Shadcn/UI components (Radix primitives, new-york style)
  - `components/seo/` — SEO meta/schema components
  - `hooks/` — Custom React hooks
  - `data/` — Static data files
  - `lib/queryClient.ts` — TanStack Query config
- `server/` — Express API
  - `routes.ts` — API endpoints (`POST /api/contact`, `POST /api/contacts`, `GET /api/contacts`)
  - `storage.ts` — Storage interface with in-memory implementation
  - `services/` — External integrations (SendGrid, Google Sheets, HubSpot)
  - `vite.ts` — Vite dev middleware setup
- `shared/schema.ts` — Drizzle ORM schemas + Zod validation (shared between client/server)
- `location_pages/` — 51 static HTML pages for Melbourne suburbs (generated by `main.py`)

### Path Aliases

- `@/` → `client/src/`
- `@shared/` → `shared/`
- `@assets/` → `attached_assets/`

### Key Patterns

- **Forms:** React Hook Form + Zod validation using schemas from `shared/schema.ts`
- **Server state:** TanStack Query for API calls
- **Styling:** Tailwind CSS with CSS variable-based theming
- **Contact flow:** Form submission → Express API → stores in memory + sends to Google Sheets, HubSpot, SendGrid (services fail gracefully)
- **Location pages:** Python script (`main.py`) generates 51 suburb-specific HTML pages from `template.html`

### Database

PostgreSQL via Neon (serverless). Drizzle ORM with schemas in `shared/schema.ts`. Tables: `users`, `contacts`. Requires `DATABASE_URL` env var.

### Deployment

Configured for Replit autoscale. Single Node.js process serves both API (port 5000) and static files. In dev, Vite middleware handles frontend; in production, Express serves `dist/public`.
